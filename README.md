# Game Soundboard

Windows 实时麦克风与本地音频混音工具。它将真实麦克风和选定的音乐、语音或音效同时输出到 VB-CABLE。

## 使用方法

1. 在“真实麦克风”中选择你实际使用的麦克风。
2. 在“混音输出”中选择 `CABLE Input (VB-Audio Virtual Cable)`。
3. 点击“启动混音”。
4. 点击“添加音频”，或直接把音频、含音频的文件夹拖进列表。
5. 在游戏中将麦克风设置为 `CABLE Output (VB-Audio Virtual Cable)`。

独占全屏游戏中不要点击音效板窗口。将音效板最小化后，按数字小键盘 `Num1` 到 `Num9` 播放当前快捷键组，按 `Ctrl+Alt+左方向键` 或 `Ctrl+Alt+右方向键` 切换组，按数字小键盘 `Num0` 停止素材。快捷键组可以循环切换，因此素材数量不受九条限制。

选中任意素材并点击“设置快捷键”，可以为该素材指定独立的全局组合键。自定义组合键在所有快捷键组中始终有效，并保存在设置中。单独的 `Num0` 到 `Num9` 为内置控制保留，不能用于自定义素材。

也可以取消勾选 Ctrl、Alt、Shift，直接绑定单独的字母键（例如 `V`）。单键会被音效板全局占用，其他程序或游戏可能无法再收到该按键。

如果游戏听不到音乐，请关闭游戏语音设置里的降噪、回声消除、噪声门和自动增益。

勾选“启用监听”并选择本机耳机或扬声器后，可以在混音前分别监听输入。勾选“监听麦克风”只监听真实麦克风，勾选“监听素材”只监听播放的音频，两项都勾选则同时监听；QQ 端始终收到完整混音。使用扬声器可能让麦克风再次收到声音并产生回声或啸叫，因此建议使用耳机。监听设备或总开关改变后，需要停止并重新启动混音。

程序支持 WAV、MP3、OGG、FLAC、M4A、AAC、WMA 和 OPUS。所有素材都保存在程序旁边的 `music` 文件夹中；启动和刷新时会自动读取该文件夹及其子文件夹。添加或拖入的音频会复制到素材库，因此原文件被移动后不影响播放。设备和音量设置保存在 `%APPDATA%\GameSoundboard\settings.json`。
