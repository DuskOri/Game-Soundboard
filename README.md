# Game Soundboard

当前版本：`v1.5`

[查看完整更新日志](CHANGELOG.md)

一个Windows 实时麦克风与本地音频混音工具。可以将给定音频加入麦克风音频，输出至无畏契约等软件中。
程序内部已经搭载康神等多款语音包。

## 运行前提

本程序**必须配合虚拟声卡使用**，推荐安装 `VB-CABLE (VB-Audio Virtual Cable)`。

- 本程序的“混音输出”选择 `CABLE Input (VB-Audio Virtual Cable)`。
- QQ、游戏或其他语音软件的麦克风选择 `CABLE Output (VB-Audio Virtual Cable)`（或直接在系统声音输出选项中选择）。

## 使用方法

程序只允许运行一个实例，重复启动会提示已经运行。点击右上角关闭按钮会隐藏到系统托盘，混音和快捷键继续运行；单击托盘图标恢复窗口，右键图标选择“退出程序”才会完全关闭。

1. 在“真实麦克风”中选择你实际使用的麦克风。
2. 在 `music` 中以子文件夹建立语音包，文件夹名即为标签名。支持前端直接拖动管理
3. 点击“启动混音”，开串！

点击语音包标签栏右侧的“在线音效包”，可查看包介绍、音频数量、下载大小和安装状态。选择音效包后点击“下载”或“同步音效包”，程序会在后台下载、校验并导入素材库；完成后会自动切换到该包，下载的音频可以离线使用。已有包出现新版本时可点击“更新”，本地自行添加或修改的音频会保留。同名但内容不同的在线音频会另存，不覆盖原文件。

在线列表通过 GitHub 获取，网络失败时会显示缓存列表并支持重试。无需登录 GitHub。包维护方式见 [在线音效包维护](soundpacks/README.md)。


独占全屏游戏中不要点击音效板窗口。将音效板最小化后，按数字小键盘 `Num1` 到 `Num9` 播放当前语音包的前九条，按 `Alt+左方向键` 或 `Alt+右方向键` 切换语音包，按数字小键盘 `Num0` 停止素材。每个语音包第十条以后的音频不会自动分配数字小键盘快捷键，但仍可鼠标播放或设置自定义快捷键。

绑定按键后被占用，无法进行正常输出。

勾选“启用监听”并选择本机耳机或扬声器后，可以在混音前分别监听输入。勾选“监听麦克风”只监听真实麦克风，勾选“监听素材”只监听播放的音频，两项都勾选则同时监听；QQ 端始终收到完整混音。使用扬声器可能让麦克风再次收到声音并产生回声或啸叫，因此建议使用耳机。监听设备或总开关改变后，需要停止并重新启动混音。

程序支持 WAV、MP3、OGG、FLAC、M4A、AAC、WMA 和 OPUS。所有素材都保存在程序旁边的 `music/语音包名/` 文件夹中；启动和刷新时会自动读取各语音包。标签栏可以横向滚动，也可通过“更多”菜单选择，因此语音包数量较多时不会溢出。设备、音量和当前语音包保存在 `%APPDATA%\GameSoundboard\settings.json`。
